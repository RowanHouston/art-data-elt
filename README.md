# art-data-elt

## Sources
There are four sources used in the dataset:
- Metropolitan Museum of Art Public API https://metmuseum.github.io/
- Kaggle Famous Paintings Dataset https://www.kaggle.com/datasets/mexwell/famous-paintings/data
- Museum of Modern Art Collection https://github.com/MuseumofModernArt/collection
- Getty Research Institute Union List of Artist Names https://www.getty.edu/research/tools/
